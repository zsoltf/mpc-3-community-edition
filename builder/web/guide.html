Setup and cheat sheet

The controller connects on its own once a project is created or loaded. No Global MIDI Learn mapping is needed.

Download the text cheat sheet

Quick start

  1. Power off the X-Touch. Hold channel 1 Select while powering it on. Set encoder 1 to MC and encoder 2 to USB, then press Select to save.
  2. Connect the X-Touch USB port directly to the MPC.
  3. With the MPC on AC power, copy the generated image to the root of a USB drive and use the MPC firmware update flow. Its filename must end in -update.img; remove any browser-added (1) suffix.
  4. After the configured MPC boots, create a blank project or load your User Template or a saved project. The controller connects when project creation or loading completes.

MIDI input setup: In MPC Preferences > MIDI/Sync, turn off Track, Global and Control for the X-TOUCH_INT input. The MCU bridge receives these controls independently; this keeps controller messages from playing notes or bending pitch on instrument tracks. Leave your other MIDI ports configured as usual. MCU support does not require Global MIDI Learn or an XMM profile. The image preserves your MIDI settings. Global MIDI Learn and optional Mini/Launch Control mappings are a separate feature.

Known limits

  • Unassigned: SMPTE/Beats, Option, Control, Alt, Trim, Touch, Latch, Marker, Nudge, Drop, Replace, transport-area Solo, Scrub and footswitch inputs.
  • Channel Solo buttons do work. Unlisted modifier combinations add no implied action.
  • Only the full X-Touch is qualified. Discovery currently depends on X-Touch device/port names; colors and motor policy are hardware-specific.
  • Other MCU devices need a device profile and hardware checks. HUI is unavailable.
  • Controller chooser navigation, synth/preset navigation, plug-in presets, Q-Link push reset, SMPTE display and pad Select/Arm are unavailable.
