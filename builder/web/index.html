MPC 3.9 CE Image Builder

MPC 3 Community Edition adds features to standalone MPCs on top of the official firmware. You build the image yourself, in this browser, from Akai's own update file; nothing is uploaded and no firmware is distributed here.

  • Mackie ControlFull Behringer X-Touch: motor faders, names, colors, meters, sends, drum pad mix, inserts, Q-Links, transport. Guide and cheat sheet.
  • Global MIDI LearnNext on the roadmap.
  • Mouse supportPlug in a USB mouse: the cursor appears after boot or on hot-plug, clicking and drag-select work, and the wheel acts as the data wheel for the focused control. The right button and long-tap gestures are not implemented yet.
  • Basic VST2 supportPlanned.

Image builder

Three steps. The result is a personal -update.img that you flash with MPC's normal firmware update. Upgrading from an earlier Community Edition image keeps your settings and projects.

  1. Official firmware

    Choose MPC-3.9.1-Gen1-update.img as downloaded from Akai. Other versions and modified files are refused.

    Download from Akai No file chosen

  2. SSH keyoptional

    Select your own Ed25519 public key (.pub) to allow root SSH login for recovery. Without a key, SSH stays disabled in the image.

    SSH disabled

  3. Create the image

    Takes a few minutes and about 2.5 GB of free memory. Keep this tab open until verification finishes, then save the file to the root of a USB drive.

    Loading the image engine

    Verified image ready
    Save image

    Keep the name ending in -update.img; remove any (1) the browser adds. Run MPC's firmware update from the USB drive.

    SHA-256

Tested on
MPC Live II 3.9.1, with the full X-Touch in MC/USB mode for the controller feature. Other Gen1 models are untested. Gen2 and Force are not supported.
This release
r5 adds USB mouse support: a pointer, clicks and drag-select, and the wheel as the data wheel for the focused control. It keeps the r4 heavy-project audio repair. Details in the release notes.
Before you flash
Back up your projects and keep the official firmware. This page builds an image; it does not flash the MPC. Reinstalling official firmware restores stock system files.
