Build your MPC 3 Community Edition image

Adds Mackie Control for the Behringer X-Touch and USB mouse support to the MPC 3.9.1 Gen1 firmware. The image is built here, in your browser, from Akai's official update file. Nothing is uploaded.

  1. Official firmware

    Choose MPC-3.9.1-Gen1-update.img as downloaded from Akai. Other versions and modified files are refused.

    Download from Akai No file chosen

  2. SSH keyoptional

    Add your Ed25519 public key (.pub) to allow root SSH login for recovery. Without a key, SSH stays disabled.

    SSH disabled

  3. Create the image

    Takes a few minutes and about 2.5 GB of free memory. Keep this tab open until verification finishes, then save the file to the root of a USB drive and run the MPC's normal firmware update.

    Loading the image engine

    Verified image ready
    Save image

    Keep the name ending in -update.img; remove any (1) the browser adds. Run MPC's firmware update from the USB drive.

    SHA-256

Included

Mackie Control, currently for the full-size Behringer X-Touch only (MC mode over USB): mixer, sends, inserts, Q-Links, transport, motor faders and meters, plus the jog wheel as the MPC data wheel (the Scrub button toggles it), the cursor cluster for data steps and Tab/Shift+Tab focus navigation, and the footswitches as Play and Record. Guide.
USB mouse: cursor, click, drag-select, wheel as the data wheel.

Requirements

MPC Live II on firmware 3.9.1. Other Gen1 models are untested; Gen2 and Force are not supported. Other MCU controllers and HUI are not supported yet. Upgrading from an earlier Community Edition image keeps your settings and projects.

Before you flash

Back up your projects and keep the official firmware. This page builds an image; it does not flash the MPC. Reinstalling official firmware restores the stock system files. Release notes.
