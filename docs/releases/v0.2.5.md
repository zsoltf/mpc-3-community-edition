# v0.2.5

- Hold MPC Shift and turn the MPC data wheel in the Grid to select the previous
  or next note.
- The browser builder can create a no-SSH debug build that keeps one current
  debug report on a marked USB drive.

For installation checks and support, Preferences > Info identifies the image
as `MPC CE v0.2.5` while retaining the stock 3.9.1 firmware value.

The X-Touch and USB mouse features remain available. X-Touch hardware is needed
only for controller features.
