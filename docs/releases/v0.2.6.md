# v0.2.6

- The Debug build now creates `MPCLEARN-DIAGNOSTICS/report.txt`
  automatically when one writable external USB drive is connected.
- The browser builder now includes the complete USB installation steps.

For installation checks and support, Preferences > Info identifies the image
as `MPC CE v0.2.6` while retaining the stock 3.9.1 firmware value.

The built-in Shift+wheel note selection, X-Touch and USB mouse features remain
available. X-Touch hardware is needed only for controller features.
